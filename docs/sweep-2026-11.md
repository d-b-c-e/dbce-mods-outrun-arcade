# Final sweep, November 2026 (SW-ORA)

Run on 2026-11-07 from 15:43 to 15:55, following `dbce-project-mgmt/docs/architecture/2026-11/06-final-sweep.md`.

- **Build:** the installed game was already the latest main build. The receipt `dbce-cannonball-controls.json` names
  source `98f69e6` (label `ora-1-98f69e6`), and the installed exe's SHA-256 matches it. Later commits change only docs.
- **Route:** started the way `Launch-Cannonball.bat` does (working folder = the game folder), but directly so the
  console log could go to a file. Keys were posted to the game window (PostMessage, no focus): Enter, the arrows, F6
  and Escape. CannonBall isn't a Steam game.
- **Layout:** the rig as it is: three 2560x1440 monitors side by side plus a fourth 1920x1080 display above them
  (`DISPLAY9` at 314,-1080). config.xml has `widescreen` 0 (4:3) and `mode` 1 (fullscreen). The game opened one
  2560x1440 window on the center monitor. There was no `Span window` log line: the span check
  (`src/main/sdl2/span.cpp`) wants every display in one row, so the fourth display turns the triple span off.
- **Safety:** lane-a lease held; `DBCE_FFB_MUTE=1`, and config.xml has haptic off. config.xml and play_stats.xml were
  backed up before each run and restored afterwards (hashes match). Escape quit the game both times. The run-2
  restore script misfired and left a file named `backup` (a byte-identical copy of play_stats.xml) in the game
  folder. I removed it, and checked config.xml and play_stats.xml by hash (`finish-run2.log`).

Captures, logs and the scripts that reproduce the run are in the git-ignored
`obj/sw-ora-20261107/` (full path
`E:\Source\game-modding\dbce-mods-outrun-arcade\obj\sw-ora-20261107\`). `start-run*.log` and `finish-run*.log` there

## For the owner to check

- **Driving with the wheel (ISS-0045):** start OutRun from LaunchBox, choose Play Game, press Start, pick music and
  drive. The wheel should steer and the pedals should accelerate and brake. No physical wheel movement was tested;
  the game ignores joystick input while its window isn't focused.
- **Wheel buttons:** the buttons in `<padconfig>` were set up when index 2 was the R12 Base. Now that the R12 is
  chosen again, they should work as before; check Start and the menu button.
- **Wheel feel:** force feedback was muted for these runs, and config.xml has haptic off.
- **Triple screens:** OutRun has a 48:9 mode (`docs/TRIPLE.md`), but it's off in config.xml (`widescreen` 0). The
  span check also skips the three monitors while the fourth display above them is on. That belongs to the
  `triple_surround` work, not this sweep.
- `Launch-Cannonball.bat` still has the old comment "2 = MOZA R12 Base (0 is vJoy)"; config.xml no longer uses the
  index.
